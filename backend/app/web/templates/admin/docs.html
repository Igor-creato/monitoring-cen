Какие поля заполнить

Для обычного мониторинга Wildberries используйте поставщика данных wildberries_direct. Apify и Zyte для этого сценария не нужны.

Перед сохранением прокси Убедитесь, что на сервере задан ADMIN_SECRETS_KEY. Без него секретные поля, включая прокси, не сохраняются из админки.

Как заполнить настройки

  1. Откройте страницу Токены и настройки провайдеров.
  2. В поле “Настройка” выберите нужное поле из таблицы выше.
  3. В поле “Новое значение” вставьте значение без лишних пробелов.
  4. Нажмите “Сохранить” и дождитесь сообщения “Настройки сохранены”.
  5. Проверьте блок “Текущие значения”: обычные поля видны полностью, секреты показываются только в замаскированном виде.

Как подключить прокси Wildberries

  1. Купите или откройте уже выданный HTTP/HTTPS прокси в личном кабинете proxy-провайдера.
  2. Скопируйте строку подключения. Поддерживаемые форматы: http://user:password@host:port или http://host:port.
  3. В админке выберите поле “Прокси Wildberries”.
  4. Вставьте прокси, например http://login:password@proxy.example.com:8000, и сохраните.
  5. После сохранения прокси не отображается обратно полностью. Это нормально: поле секретное и хранится в зашифрованном виде.
